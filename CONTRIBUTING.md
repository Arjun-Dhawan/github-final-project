
# Contributing Guidelines

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

Thank you for your interest in contributing to the Simple Interest Calculator project.

## How to Contribute

1. Fork this repository to your GitHub account.
2. Clone your fork to your local development environment.
3. Create a new branch for your changes.
4. Make your changes or improvements.
5. Test your changes before submitting.
6. Commit your changes with a meaningful message.
7. Push your branch to GitHub.
8. Open a pull request describing your contribution.

## Reporting Bugs

If you find a bug, please open a GitHub issue describing the problem, how to reproduce it, and the expected behaviour.

## Suggesting Enhancements and Ideas

Suggestions for new features, enhancements, and improvements are encouraged. Please open an issue to discuss your ideas.

## Documentation Improvements

Contributions that improve the README, instructions, examples, and other project documentation are welcome.

## Code of Conduct

All contributors are expected to follow the project's CODE_OF_CONDUCT.md.
