
# Code of Conduct

## Our Pledge

We are committed to providing a welcoming,
inclusive, and respectful environment for
everyone contributing to this project.

## Expected Behaviour

- Be respectful and considerate.
- Welcome constructive feedback.
- Respect different viewpoints.
- Collaborate professionally.

## Unacceptable Behaviour

- Harassment or discrimination.
- Personal attacks or abusive comments.
- Any behaviour that creates an unsafe environment.

## Enforcement

Project maintainers are responsible for
reviewing and addressing reported violations.
